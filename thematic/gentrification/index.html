前の時間は、先進国の大都市で中・高所得層が郊外へ移り、古い市街地（インナーシティ）が衰える「インナーシティ問題」を学んだ。では、見捨てられた都心はその後どうなったのだろうか。

STEP 2｜実例

世界の実例──街はどうやって“戻ってきた”のか

海外と日本の2つの街を比べよう。どちらも、もとは船をつくる仕事と関係の深い街だった。タブを切り替えて見てみよう。

  1. 〜1960年代　テムズ川沿いに造船所や倉庫が並ぶ、世界有数の港湾地区だった。
  2. 1960〜1980年　港がすべて閉鎖される。コンテナ船の大型化などで古い港が使われなくなったとされ、失業や空き地が広がった。
  3. 1981〜1998年　政府がつくった開発公社（LDDC）が再開発を進め、超高層のオフィス街カナリー・ワーフ、新交通システム（DLR）、空港などが整備された。
  4. 現在　高層マンションやオフィスビルが並び、高所得層が住む地区に生まれ変わった。

ロンドンの人口の移り変わり（現在の大ロンドンの範囲）

1939年：約860万人 → 1988年：約670万人（最少） → 2015年：1939年の水準を回復 → 2021年：約880万人

光：荒れた港湾跡地に雇用とにぎわいが生まれ、ロンドンの人口回復を支えた地区の一つになった。

影：新しく生まれた金融・オフィスの仕事は、もとの港湾労働者の暮らしと結びつきにくく、地元住民が恩恵を受けにくかったという批判もある。

  1. 1892年　東京湾の埋め立てで月島が誕生。となりの佃にあった造船所（石川島造船所）に関係する鉄工所や工場が集まり、そこで働く人々の長屋が並ぶ街になった。
  2. 戦後　駄菓子屋の「文字焼き」がもんじゃ焼きのルーツとされ、西仲通り商店街は「もんじゃストリート」として知られるように。
  3. 1988年　地下鉄有楽町線の月島駅ができ、銀座など都心へのアクセスがぐっと便利に。
  4. 2000年代〜　タワーマンションが次々に建つ。2020年には商店街のとなりで32階建ての再開発ビルが完成し、月島には10棟以上のタワーマンションが並ぶ。

光：古い木造長屋が密集した地区を建て替え、災害（火事や地震）に強い街にする。新しい住民が増え、街ににぎわいが生まれる。

影：「月島にもう超高層はいらない」「日影が長い時間広がる」「人口が急に増える」として、再開発に反対する運動も起きた。路地や長屋、近所づきあいなど、下町らしさが失われる心配もある。

※欧米のインナーシティのように「荒れて貧しい人が残された街」ではなく、古い木造住宅が多い下町だった点が違う。日本版のジェントリフィケーションとされる例。

都心では…

高度経済成長期からバブル期にかけて、都心は地価が高く人口が減った（ドーナツ化現象）。バブル崩壊後に地価が下がると、空き地や駐車場に分譲マンションが建ち、人口の都心回帰が進んだ。

そのころ郊外では…

1970〜80年代に建てられたニュータウンで高齢化が進み、空き家や空き地がまばらに増える都市のスポンジ化が課題に。2025年の国勢調査速報では、東京都の区部は増えた一方、市部（多摩地域）が初めて減少した。

都心に人が戻ると、郊外では何が起こるだろう？

STEP 6｜確認

確認クイズ

Q1. ジェントリフィケーションの説明として、最も適当なものはどれか。

解説：2はスプロール現象、3はドーナツ化現象（郊外化）、4はセグリゲーション。ジェントリフィケーションは、インナーシティ問題の「その後」に起こる、高所得層の流入による街の変化を指す。

Q2. ロンドン・ドックランズと東京・月島の説明の組み合わせとして正しいものはどれか。

解説：ドックランズは使われなくなった港を開発公社が大規模に再開発した例。月島は造船関係の工場で働く人の長屋が並んだ下町に、地下鉄の開通や再開発でタワーマンションが建ち並んだ例。どちらも新しい住民が増える一方、元からの街の姿や暮らしが変わる点は共通する。なお教科書のニューヨークは、芸術家が住み始めたことがきっかけだった。

Q3. ジェントリフィケーションの「影」の側面として、適当でないものはどれか。

解説：高所得層が出ていき税収が減るのは、ジェントリフィケーションの前に起こる「インナーシティ問題」の特徴。ジェントリフィケーションではむしろ高所得層が流入し、税収は増える方向にはたらく。
